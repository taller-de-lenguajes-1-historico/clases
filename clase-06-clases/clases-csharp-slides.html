Introducción

Programación orientada a objetos

La POO es un paradigma de programación que busca crear abstracciones del mundo real a través de objetos.

¿Qué es una clase?

  • La unidad atómica de un sistema orientado a objetos.
  • Una estructura de datos.
  • Permite la creación de objetos.
  • Encapsula estado (datos) y comportamiento (acciones).
Aprender un paradigma nuevo: «¿por qué?… ah, por eso».
Clase · Declaración

Declarar una clase

Declaramos una nueva clase llamada MiClase. Si venís de C, es la evolución del struct: además de datos, agrupa comportamiento.

Clase en C#

class MiClase
{
   // miembros y atributos
   // de la clase
}

Comparación: struct en C

typedef struct MiEstructura
{
   // miembros de
   // la estructura
}
Clase · Objetos

Crear objetos (instancias)

MiClase MiInstancia = new MiClase();

Clase

Es el molde: define qué datos y qué comportamiento tendrán los objetos de ese tipo.

Objeto o instancia

Cada variable del tipo de la clase es un objeto. Cada objeto creado a partir de la clase se llama instancia.

El operador new reserva memoria dinámicamente para crear la instancia.

Miembros · Campos

Campos o atributos

Llamamos campo (o atributo) a una variable declarada dentro de una clase. Representan el estado del objeto.

Declarar campos

class MiClase
{
   int x;
   int y;
}

Usar un campo

MiClase MiInstancia = new MiClase();

// acceso con el operador "."
MiInstancia.x = 10;
Miembros · Visibilidad

Visibilidad: público vs privado

Miembros públicos

public class Perro
{
   public string Nombre;
   public string Raza;
   public int Edad;
}

Perro mi = new Perro();
mi.Edad = 10;   // OK: accesible con "."

Accesibles desde afuera de la clase.

Miembros privados

public class Perro
{
   private string Nombre;
   private string Raza;
   private int edad;
}

Perro schnauzer = new Perro();
schnauzer.edad = 10;   // ERROR ✗

Accesibles solo desde dentro de la clase. ¡No podés acceder a un miembro privado desde afuera!

Miembros · Propiedades

Propiedades (getters y setters)

Exponer un campo privado

public class Perro
{
   private int edad;
   public int Edad
   {
      get => edad;
      set => edad = value;
   }

   private string nombre;
   public string Nombre
   {
      get => nombre;
      set => nombre = value;
   }
}

¿Para qué sirven?

Una propiedad es una función que permite acceder a las variables declaradas dentro de una clase.

Dejan que la clase exponga una manera pública de obtener (get) y establecer (set) valores, mientras oculta la implementación o la verificación.

mi.Edad = 5;        // usa set
int e = mi.Edad;   // usa get
Métodos

Métodos

Un método es un bloque de código con instrucciones. Llamarlo en un objeto es como acceder a un campo: nombre del objeto + . + nombre del método + ().

Definir un método

public class Perro
{
   private int edad;
   public int Edad { get => edad; set => edad = value; }

   public int EdadEnAniosPerro()
   {
      return edad * 7;
   }
}

Llamar al método

Perro fangio = new Perro();
fangio.Edad = 3;

Console.WriteLine(
   fangio.EdadEnAniosPerro());  // 21

El programa ejecuta las instrucciones del método al llamarlo.

Métodos · Constructor

El constructor

Inicializar al crear el objeto

public class Perro
{
   private string raza;

   // constructor: mismo nombre que la clase
   public Perro(string raza)
   {
      this.raza = raza;
   }
}

Perro fangio = new Perro("schnauzer");
El constructor lleva el mismo nombre que el tipo y no declara tipo de retorno. Se ejecuta al hacer new.
Ejemplo práctico

La clase Player

Agrupamos un conjunto de elementos con características comunes: un jugador tiene posición y vidas (datos), y puede saltar (comportamiento).

public class Player
{
   public float PosicionX;
   public float PosicionY;
   public int Vidas;

   public void Saltar()
   {
      PosicionX += 5;
      PosicionY += 10;
   }
}
La clase es el molde: define los datos y el comportamiento, pero todavía no es un objeto concreto.
Ejemplo práctico · Instancias

Dos objetos del mismo molde

Del mismo Player creamos instancias independientes: cada una tiene su propio estado.

Player mario = new Player();
mario.PosicionX = 20;
mario.PosicionY = 10;
mario.Vidas = 3;
Player luigi = new Player();
luigi.PosicionX = 30;
luigi.PosicionY = 10;
luigi.Vidas = 3;
Ejemplo práctico · Métodos

Usar un método: Saltar()

Llamar al método modifica el estado de ese objeto en particular (su posición).

mario.Saltar();
luigi.Saltar();
Organización

Espacios de nombre (namespace)

Un namespace agrupa clases relacionadas; un proyecto agrupa varios namespaces. Sirve para organizar y evitar choques de nombres.

namespace MiJuego
{
   class Player { }
   class Enemigo { }
   class Nivel { }
}

Jerarquía

  • Proyecto → varios namespaces
  • Namespace → varias clases
  • Clase → campos y métodos

Para usar una clase de otro namespace: using MiJuego;

Resumen

Anatomía de una clase

Las clases representan entidades o conceptos, como los sustantivos del lenguaje. Cada clase es un modelo con dos partes:

Datos — el estado

Representado por los campos o atributos. Describen qué es y cómo está el objeto.

campos · propiedades

Comportamiento

Representado por los métodos. Describen qué puede hacer el objeto y operan sobre sus datos.

métodos
Una clase encapsula estado + comportamiento en una sola unidad. Los objetos son instancias concretas de ese modelo.
Clase estática

Clases estáticas

Una clase estática no se puede instanciar (no usa new): solo agrupa miembros estáticos. Útil para utilidades y helpers.

Definir y usar

public static class Calculadora
{
   public static int Sumar(int a, int b)
   {
      return a + b;
   }
}

// se usa sin crear instancia:
int r = Calculadora.Sumar(2, 3);  // 5

Características

  • No se crea con new.
  • Todos sus miembros son static.
  • Se accede por el nombre de la clase.
  • Ejemplos del framework: Math, Console.

Repaso & cierre

En una línea

Una clase es un molde que encapsula datos (campos/propiedades) y comportamiento (métodos). Los objetos son instancias creadas con new.

Conceptos clave

  • Campos = estado · Métodos = comportamiento
  • public / private controlan la visibilidad
  • Propiedades = get / set sobre campos privados
  • El constructor inicializa el objeto al hacer new
  • Clase estática = sin instancias
