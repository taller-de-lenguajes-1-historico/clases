# Clase 7 — Colecciones en C#

Trabajar con un grupo de objetos: **arreglos**, **tipos genéricos**, **colecciones** y **enum**.

## Contenido

- `colecciones-csharp-slides.html` — presentación (21 slides).
- `img/` — imágenes usadas en la presentación.
- `proyecto-ejemplo/` — proyecto de consola .NET con todos los ejemplos del deck, ejecutables.

## Temas

1. Arreglos: declaración, inicialización, dimensiones, una imagen como tensor.
2. Genéricos: declaración, implementación y sustitución de `T`.
3. Colecciones: espacios de nombre, tipos (`List`, `Dictionary`, `Queue`, `Stack`), uso.
4. Listas: operaciones, formas de recorrer (iteradores) y listas de objetos.
5. LINQ simple (filtrar, proyectar, agregados).
6. Enum y `[Flags]`.

## Ver la presentación

Abrí `colecciones-csharp-slides.html` en el navegador.

## Correr los ejemplos

```bash
cd proyecto-ejemplo
dotnet run
```
