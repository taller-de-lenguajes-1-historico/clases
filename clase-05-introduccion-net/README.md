# Clase 5 — Introducción a C# y .NET

El lenguaje C#, sus características y posibilidades; el SDK .NET y su línea de comandos (CLI); tipos de datos, estructuras de control y cómo compila .NET.

## Contenido

- `introduccion-net-slides.html` — presentación (24 slides).
- `img/` — imágenes usadas en la presentación.
- `proyecto-ejemplo/` — proyecto de consola .NET con ejemplos ejecutables.

## Temas

1. ¿Qué es C#? características y qué se puede programar.
2. Lenguajes interpretados vs compilados; librería / API / SDK / framework.
3. Ecosistema .NET (Framework, Mono/Xamarin, .NET Core → .NET 5+), IDEs.
4. La CLI de .NET: anatomía de un comando y comandos útiles.
5. Estructura de un proyecto de consola (.csproj, ImplicitUsings, Nullable).
6. Sistema de tipos: valor vs referencia, tipos simples, struct, string, nullable, DateTime.
7. Estructuras de control: if/switch y ciclos (for, while, do-while, foreach).
8. Cómo compila .NET: Roslyn → IL → CLR → JIT → nativo.
